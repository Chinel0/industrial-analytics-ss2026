### Experiment 3: Interaction Features on the Key Cost Drivers

The EDA showed that cost depends on combinations of physical properties, for example diameter together with length. A purely linear model cannot represent such interactions. This experiment adds degree-2 polynomial and interaction terms for the main physical cost drivers and trains the tuned Ridge model on the expanded feature set.

=== CELL 213 [code] ===
from sklearn.preprocessing import PolynomialFeatures
from sklearn.compose import ColumnTransformer

key_feats = [c for c in ['diameter', 'wall', 'length', 'quantity',
                          'Total_weight', 'num_bends',
                          'min_order_quantity', 'annual_usage']
             if c in X_train.columns]
other_feats = [c for c in X_train.columns if c not in key_feats]

pre = ColumnTransformer([
    ('poly', PolynomialFeatures(degree=2, include_bias=False), key_feats),
    ('rest', 'passthrough', other_feats)

exp3_pipe = Pipeline([

## 9.5 Error Analysis

Confusion matrices apply to classification models. Since this is a regression task, the equivalent error analysis tools are:

1. **Residual distribution:** the histogram of prediction errors should be centred at zero
2. **Residuals vs predicted values:** patterns here reveal systematic bias
3. **Error by cost bracket:** the regression counterpart of a confusion matrix, showing in which price range the model succeeds and in which it fails

The next cell produces all three for the enhanced model on the test set.

=== CELL 219 [code] ===

### Root Cause Analysis

The error analysis shows a consistent pattern with three root causes:

1. **Data imbalance across price ranges.** The vast majority of test quotes lie below $20, while expensive assemblies above $100 are rare. The model has very few examples to learn high-cost pricing behaviour from, so its absolute error grows steeply with the cost bracket.

2. **The linearity assumption.** Supplier pricing combines fixed costs (tooling, setup) with variable costs that interact, for example quantity discounts that depend on the complexity of the assembly. A linear model cannot fully represent such interactions, which is why even the enhanced versions plateau.

3. **Back-transformation amplification.** The model is trained on the power-transformed scale. Converting predictions back to dollars raises them to the power of 20, which amplifies small transformed-scale errors into large dollar errors exactly in the expensive range.

These causes explain why the mean absolute error per bracket rises with the cost while the typical quote (the 0 to 20 dollar range that dominates procurement volume) is predicted with a small error.

## 9.6 Limitations and Evaluation Summary

**Limitations**

1. The model family is linear. The flat tuning curves and the experiment log show that parameter tuning and feature work give only marginal gains; the remaining gap to a better score requires non-linear models such as the gradient boosting approaches developed by the other team members.
2. High-cost assemblies are underrepresented in the data, which limits any model trained on it, regardless of algorithm.
3. The specification dataset could not be used because the lookup table that explains the specification codes is missing.
4. Quotes are heavily concentrated in the 2010 to 2014 period, so the model reflects the pricing situation of that time and would need retraining on current data before production use.

**Evaluation summary**

The evaluation followed the required methodology: a 3-way split with a sealed test set, baseline comparison justified by 5-fold cross-validation, hyperparameter tuning with GridSearchCV on the training set only, validation of the chosen parameters on the held-out validation set, documented enhancement experiments and one final evaluation on truly unseen test data. The deliverables of this task are the validation analysis report (9.1), the enhanced model version (9.4, saved as enhanced_model.pkl), the enhancement log (9.3), the test evaluation report (9.4), the error analysis (9.5) and this summary.
